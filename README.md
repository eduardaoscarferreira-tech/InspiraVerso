# InspiraVerso

Seu universo de inspiração literária.

O InspiraVerso é um aplicativo para Windows de inspiração e escrita: Ateliê de Escrita, Ateliê de Composição, Biblioteca de Inspirações, Oficina Criativa, obras, personagens, RPG, Universo Musical e Mentor Literário com a IA da sua escolha (Gemini, OpenAI, Claude ou Grok, com a sua própria chave).

Feito para ser usado com o leitor de tela NVDA e com o teclado.

## Como baixar

Abra a seção Releases (Versões) desta página e baixe um dos arquivos da versão mais recente:

- InspiraVerso_X_Instalar-ou-Portatil.exe: permite instalar no computador ou criar uma cópia portátil.
- InspiraVerso_X_Portatil.zip: cópia portátil, é só descompactar e abrir o InspiraVerso.exe.

O Windows pode avisar que o editor é desconhecido, porque o instalador não tem assinatura digital.
