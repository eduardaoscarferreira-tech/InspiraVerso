# InspiraVerso

Seu universo de inspiração literária: um aplicativo para Windows de inspiração e escrita, feito para ser usado com o leitor de tela NVDA e com o teclado.

## Como baixar

A versão mais recente fica neste endereço:

https://github.com/eduardaoscarferreira-tech/InspiraVerso/releases/latest

Baixe o arquivo que termina em Instalar-ou-Portatil.exe e abra. Ele pergunta se você quer instalar o InspiraVerso no computador ou criar uma cópia portátil numa pasta à sua escolha.

O Windows pode avisar que o editor é desconhecido, porque o instalador não tem assinatura digital.
